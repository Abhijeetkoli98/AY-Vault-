Restoration Protocol

Backups are encrypted using AES-256-GCM authenticated encryption derived from your enterprise master passphrase via PBKDF2-HMAC-SHA256 (600,000 iterations). Restoring a backup overwrites the active database with the archive snapshot and verifies cryptographic file hashes. Only authorized Administrators can execute restoration procedures.
